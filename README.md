# Misión Primer Grado 2027

Repositorio exclusivo para el sitio escolar. No está relacionado con Infinity Brows ni CAVI.SYSTEM.

El sitio completo se distribuye en un paquete ZIP con `index.html` y la carpeta `assets/`. Para GitHub Pages, estos archivos deben subirse descomprimidos a la raíz de la rama `main`, y habilitarse Pages en Settings → Pages → Deploy from a branch → main / (root).

Backend: Supabase, proyecto `gxknengoiokwlrbxgdfs`. Revisar configuración de dominios permitidos para acceso antes de poner el sitio en producción.
